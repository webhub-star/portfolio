# 이름 연락처 응원 메시지 개인정보동의 마케팅동의 신청 일시 관리

🧭 비영리 기부자 획득 및 육성 퍼널 (Donor Funnel)

1회성 방문자를 정기 후원자로 단계적 전환시키는 3-Phase CRM 퍼널 구조입니다.

Phase 01. 참여 유도
1분 기도 릴레이

전환 장치: 비용 없는 1분 행동 약속, 인터랙티브 촛불 카운터, 참여 장벽 최소화.

Phase 02. 결과 피드백
감사 리포트

전환 장치: 카카오톡 1:1 메시지 발송, 현지 의료진 감사 영상, 터치 스와이프 사진 제공.

Phase 03. 신뢰 및 후원
현장 소식 & 정기 후원

전환 장치: 2025 연차보고서 투명 공개, 국제 NGO 공신력 입증, 온라인 정기 후원창 연계.

🛠️ 관리자 백오피스 & 개인정보 데이터 거버넌스

기부자 데이터의 안전한 관리, CSV 내보내기를 통한 현업 연계, 개인정보보호법에 준거한 파기 절차를 구축했습니다.

📋 데이터 파이프라인 및 백오피스 기능

  • 인라인 단일 관리자 인증: 별도 계정 등록 없이 비밀키 기반의 직관적 관리자 로그인 지원
  • 실시간 Firestore 데이터 조회: 서버리스 NoSQL 데이터베이스로부터 최신 등록순 역정렬 렌더링
  • CSV/엑셀 내보내기: UTF-8 BOM(`\uFEFF`) 인코딩 처리를 통해 엑셀 한글 깨짐 원천 방지
  • 단건 삭제 및 일괄 파기: 실수로 인한 데이터 손실을 방지하는 2단계 확인 절차(문구 입력 확인)

⚖️ 컴플라이언스 및 개인정보 보호

  • 선택/필수 동의 분리: 개인정보 수집 동의(필수)와 선교·후원 마케팅 안내(선택) 엄격 구분
  • 보유 기간 경과 시 파기 로직: 목적 달성 후 지체 없는 파기를 위한 '일괄 파기' API 탑재
  • XSS 방어 데이터 이스케이프: 악의적인 스크립트 태그 입력 방지를 위한 `escapeHtml` 헬퍼 적용

⚙️ 시스템 보안 및 브라우저 제어 매트릭스

모바일 인앱 브라우저 및 웹 데스크톱 환경에서 발생하는 무단 복제 및 불법 조작을 차단합니다.

  • 우클릭 원천 차단: `contextmenu` 이벤트를 가로채어 우클릭 메뉴 비활성화
  • 텍스트 드래그 차단 & 폼 예외: 전체 드래그를 금지하되 폼 입력 필드는 상호작용 유지
  • 개발자 도구 단축키 방지: `F12`, `Ctrl+U`, `Ctrl+Shift+I/J/C`, `Ctrl+S` 차단

💻 주요 스크립트 로직 분석

// UTF-8 BOM 인코딩을 적용한 CSV 다운로드 const exportCSV = (dataList) => { let csv = "\uFEFF이름,연락처,응원메시지,개인정보동의,마케팅동의,신청일시\n"; dataList.forEach(item => { const dateStr = item.createdAt?.toDate ? item.createdAt.toDate().toLocaleString('ko-KR') : '-'; csv += `"${item.name}","${item.contact}","${item.message}","${item.consent?'동의':'미동의'}","${item.marketingConsent?'동의':'미동의'}","${dateStr}"\n`; }); const blob = new Blob([csv], { type: 'text/csv;charset=utf-8;' }); const link = document.createElement("a"); link.href = URL.createObjectURL(blob); link.download = `기도릴레이_접수명단_${new Date().toISOString().slice(0,10)}.csv`; link.click(); };
