Non-Profit CRM Strategy

기부 피로도를 낮추는 3단계 기부자 성장 여정 (Donor Lifecycle CRM)

일반적인 NGO 모금 웹페이지는 유입 즉시 정기결제를 요구하여 이탈률이 90%에 달합니다. 본 프로젝트는 [1분 기도 릴레이]라는 심리적 허들이 극히 낮은 미션으로 초기 참여를 유도한 후, [감사 리포트]와 [현장 소식]을 통해 투명성과 신뢰를 제공하여 자발적 정기후원으로 전환시키는 고도화된 퍼널을 구축했습니다.

🕯️
Phase 1: 유입 및 공감

1분 기도 & 응원 릴레이

핵심 지표: 영상 재생 완료율, 갤러리 스와이프율

2. CSS Scroll-Snap 갤러리와 Active Dot 동기화

JS + CSS Snap 
// 무거운 Swiper.js 없이 바닐라 이벤트로 구현한 부드러운 스와이프 도트 반응
const track = document.getElementById('galleryTrack');
const dots = document.querySelectorAll('.dot');

track.addEventListener('scroll', () => {
  // 개별 아이템 폭 + 마진(12px)을 기준으로 현재 스크롤 인덱스 산출
  const itemWidth = track.firstElementChild.getBoundingClientRect().width + 12;
  const activeIndex = Math.round(track.scrollLeft / itemWidth);

  dots.forEach((dot, index) => {
    if (index === activeIndex) {
      dot.classList.add('active'); // 너비 20px로 확장 애니메이션
    } else {
      dot.classList.remove('active');
    }
  });
});
