🧭 비영리 기부자 획득 및 육성 퍼널 (Donor Funnel)

단순한 후원 유치 폼의 한계를 극복하기 위해, 감정적 공감에서 시작하여 신뢰 검증 및 최종 후원 전환으로 이어지는 3단계 CRM 라이프사이클을 설계했습니다.

Step 01. 잠재 후원자 획득
1분 기도 & 응원 릴레이

목표: 심리적 진입 장벽 제거 및 자발적 모바일 참여 유도

핵심 장치: 비용 부담 없는 '1분 기도' 액션, 실시간 촛불 카운터 게이미피케이션, 필수 수집 항목의 최소화(이름, 연락처).

Step 02. 투명성 피드백 & 신뢰 형성
위드헤브론 감사 리포트

목표: 참여 결과 피드백을 통한 효능감 증대

핵심 장치: 카카오 알림톡을 통한 1:1 감사 메시지 도달, 현지 의료진/환아의 감사 영상 및 터치 슬라이드 갤러리 제공.

Step 03. 정기 후원자 전환
현장 소식 & 기관 검증 리포트

목표: 일회성 참여자의 정기 동역자(정기기부자) 전환

핵심 장치: 2025 연차보고서 투명 공개, 지속가능한 보건의료 프로젝트 안내, MRM 간편 후원 결제창 연동.

⚙️ 프론트엔드 보안 정책 및 시스템 구조

외부 무단 크롤링, 폼 자동 입력 봇, 모바일 인앱 브라우저 내 텍스트 오선택을 방지하기 위해 정교한 클라이언트 보안 레이어를 구축했습니다.

🔒 적용된 브라우저 보안 제어 매트릭스

  • 우클릭 차단 (Context Menu Blocking): `oncontextmenu="return false;"` 및 이벤트 리스너를 통한 우클릭 무력화
  • 텍스트 드래그/선택 차단 (Select/Drag Blocking): CSS `user-select: none;` 적용 및 폼 입력 필드(`input`, `textarea`)에 대한 선택 복원 예외 처리
  • 개발자 도구 단축키 무력화: `F12`, `Ctrl+U`(소스보기), `Ctrl+Shift+I/J/C`(검사 도구), `Ctrl+S`(페이지 저장) 키 이벤트 원천 차단
  • 서버리스 Firestore 통신: Google Firebase v10 모듈러 SDK를 통한 안전한 비동기 데이터 적재

💻 주요 스크립트 로직 분석

1. 우클릭 및 단축키 차단 스크립트 (보안 모듈)

// 우클릭, 드래그 및 개발자 단축키 차단 document.addEventListener('contextmenu', e => e.preventDefault()); document.addEventListener('dragstart', e => e.preventDefault()); document.addEventListener('selectstart', e => { // 사용자가 입력 필드(input, textarea)를 드래그하는 경우는 허용 if (['INPUT', 'TEXTAREA'].includes(e.target.tagName)) return true; e.preventDefault(); }); document.addEventListener('keydown', function(e) { if (e.key === 'F12') e.preventDefault(); if ((e.ctrlKey || e.metaKey) && e.key.toLowerCase() === 'u') e.preventDefault(); if ((e.ctrlKey || e.metaKey) && e.shiftKey && ['i','j','c'].includes(e.key.toLowerCase())) e.preventDefault(); });
