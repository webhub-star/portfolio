핵심 로직 분석 & 코드 해설

캠페인의 완성도를 높인 핵심 3가지 기능의 구현 디테일입니다.

1. 마감 시점(2026.09.21) 자동 제어 및 안내창 전환

JavaScript 
// 한국 표준시(KST) 기준 마감 시각 자동 분기
function checkDeadline() {
  const deadline = new Date("2026-09-21T00:00:00+09:00").getTime();
  const now = Date.now();

  // 2026년 9월 21일 00:00 기준 마감 시 폼 숨김 & 감사 메시지 박스 표출
  if (now >= deadline) {
    form.style.display = 'none';
    closedNotice.style.display = 'block';
    return true;
  }
  return false;
}

설계 의도: 캠페인이 종료된 후 별도의 소스 코드 재배포 없이도 브라우저 접속 즉시 마감 안내 모드로 자동 전환되도록 하여 관리 공수를 최소화했습니다.

2. 실시간 참여 기반 촛불 릴레이 동적 렌더링

JS + CSS Keyframes 
const CANDLE_COUNT = 12;

// 참여 수(count)에 맞춰 lit 클래스를 동적으로 주입하여 애니메이션 부여
function lightCandles(count) {
  const candles = relayRow.querySelectorAll('.candle');
  const litCount = Math.min(count, CANDLE_COUNT);
  candles.forEach((c, i) => {
    if (i < litCount) {
      c.classList.add('lit');
    } else {
      c.classList.remove('lit');
    }
  });
}

설계 의도: 12개의 촛불을 생성하고, 참여자가 늘어남에 따라 은은하게 불꽃이 일렁이는 플리커(Flicker) CSS 효과를 활성화하여 "내 기도가 불빛이 되어 더해진다"는 심리적 만족감을 선사합니다.

3. 우클릭/드래그 방지 및 사용자 입력 영역 예외 처리

CSS + Event Listeners 
/* CSS: 전체 영역 텍스트 드래그 방지 및 입력창 예외 처리 */
* { user-select: none; }
input, textarea { user-select: auto !important; }

// JS: 개발자 도구 및 소스보기 주요 단축키 차단
document.addEventListener('contextmenu', e => e.preventDefault());
document.addEventListener('keydown', e => {
  if (e.key === 'F12' || 
     ((e.ctrlKey || e.metaKey) && ['u', 's'].includes(e.key.toLowerCase())) ||
     ((e.ctrlKey || e.metaKey) && e.shiftKey && ['i', 'j', 'c'].includes(e.key.toLowerCase()))) {
    e.preventDefault();
  }
});

설계 의도: 중요한 캠페인 텍스트와 레이아웃의 무단 도용을 예방하며, 입력창(`input`, `textarea`)은 `user-select: auto !important`로 예외 처리하여 실사용자의 작성 편의성은 그대로 유지했습니다.
